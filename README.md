# Food-time-prediction

An end-to-end regression project that predicts food delivery time (in minutes) for Swiggy orders across Indian cities. The project covers data cleaning, feature engineering, a missing-data experiment, model benchmarking with Optuna, and a tuned Stacking Ensemble.

Tech Stack: Python, Pandas, NumPy, Scikit-Learn, LightGBM, XGBoost, Optuna, Matplotlib, Seaborn, Missingno
